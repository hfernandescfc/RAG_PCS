# RAG_PCS

Retrieval-Augmented Generation (RAG) application built to support document search and question answering over Programa Cidade Saneada documentation.

## Overview
The project processes technical documents, prepares them for retrieval, and enables AI-assisted question answering over the knowledge base. The goal is to improve access to domain documentation and reduce manual search effort.

## Main Components
- Document ingestion and preprocessing
- Chunking and indexing
- Retrieval pipeline
- LLM-based answer generation
- Supporting scripts for document processing and updates

## Use Case
Designed for users who need to query program documentation quickly and obtain contextual answers grounded in source material.

## Tech Focus
This project showcases applied AI engineering skills in:
- document processing
- retrieval pipelines
- RAG system design
- prompt/context management
- domain-specific knowledge access
